公众号排版助手

粘贴 Markdown，选好配色，一键复制成微信兼容的图文排版。

纯前端 · 内容不上传 单文件 · 可离线
① 粘贴 Markdown→ ② 选配色与章节样式→ ③ 复制，粘进公众号编辑器 （默认开启「公众号强兼容模式」，也可点「载入语法演示」先看效果）
怎么用 / 支持哪些 Markdown 写法（点击展开）
  • # 标题 → 顶部主色大标题；紧随的 > 引用行 变成副信息（栏目 / 作者 / 日期）。
  • ## 章节标题 → 一个圆角卡片；写「## 1. 标题」或自动编号，序号支持 5 种样式。
  • - **标签**：内容 → 自动变成彩色标签 chip，适合「核心亮点 / 适用对象 / 落地价值」这类四要素。
  • 支持 **加粗**、*强调*、> 引用、--- 分隔线、有序/无序列表。
  • 结尾含「共同点 / 结语 / 写在最后 / 总结」的章节会变成 CTA 块；整行斜体 *文字* 自动变小字脚注。
  • 公众号强兼容模式（默认开）：只用「浅底 + 深字」，配色靠字色、左边框和标签表达。微信编辑器即使把背景色清掉，文字依然清晰，不会出现白字白底。
  • 关闭强兼容模式（标准模式）会恢复深色 Hero 与深色 CTA，视觉更强，适合「下载 HTML → 打开后全选复制」或编辑器保留样式较完整的情况。
  • 复制后到公众号编辑器按 Ctrl/⌘ + V，样式会一起带过去；如编辑器仍清空样式，改用「下载 HTML」打开后全选复制，或直接复制 Markdown 纯文本。

① 配色模板（点选即时生效）

任选颜色，自动派生配套的浅底、标签色与强调色。

② 排版参数

强兼容模式下所有文字都是深色、底色都是浅色；即使公众号编辑器清洗了背景色，正文也不会「消失」。设置会记在本机浏览器。

③ 粘贴 / 编辑 Markdown

支持拖放 .md 文件到输入框

④ 输出

复制后到公众号编辑器直接粘贴；强兼容模式下背景被清掉也不会白字白底。
